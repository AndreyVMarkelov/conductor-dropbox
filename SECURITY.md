# Security Policy

## Reporting a Vulnerability

Please do not open public issues for suspected security vulnerabilities.

Use GitHub private vulnerability reporting for this repository when available.

If private vulnerability reporting is unavailable, contact the repository maintainer without publicly disclosing exploit details.

Please include, when possible:

- affected version or commit
- description of the impact
- reproduction steps
- relevant logs
- proof of concept

Security reports will be reviewed as soon as practical. Fixes and disclosure will be coordinated before vulnerability details are made public when appropriate.

## Secrets

Never commit Dropbox access tokens, refresh tokens, application credentials, or other secrets to this repository.

Use environment variables or your deployment platform's secret-management system.
